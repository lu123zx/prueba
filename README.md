# Royal Vega · Club & Casino Privé

Casino privado entre amigos — **solo fichas de juego, sin dinero real**.

- Next.js (App Router) + Tailwind v4
- Supabase: login con Google / Apple / enlace mágico, saldos y juegos validados en el servidor (RPC)
- Juegos: Royal 777 (tragamonedas), Ruleta Imperial (europea), Blackjack VIP
- Bono diario de 25.000 fichas, ranking del club e historial

## Desarrollo
```bash
npm install
cp .env.example .env.local   # completa la clave publicable
npm run dev
```
